# Proyecto Final Módulo 4 

## Descripción
Este proyecto corresponde al Módulo 4 del curso y consiste en una aplicación desarrollada en JavaScript que se ejecuta en la consola del navegador.

La aplicación permite realizar operaciones matemáticas básicas, utilizar estructuras de control, funciones, arreglos y objetos, aplicando los conceptos fundamentales del lenguaje JavaScript.

---

## Funcionalidades
- Ingreso de datos por medio de prompt
- Operaciones matemáticas básicas:
  - Suma
  - Resta
  - Multiplicación
  - División
- Uso de condicionales (if, switch)
- Uso de ciclos (for, forEach)
- Manipulación de arreglos
- Uso de objetos y métodos
- Validación de datos ingresados

---

## Tecnologías utilizadas
- JavaScript
- Consola del navegador
- Visual Studio Code

---

## Cómo ejecutar el proyecto
1. Abrir el archivo app.js
2. Copiar el código
3. Abrir el navegador
4. Presionar F12 y entrar a la pestaña **Consola**
5. Pegar el código y presionar Enter

---

## Evidencias
El proyecto incluye capturas de pantalla de la aplicación funcionando en la consola.
